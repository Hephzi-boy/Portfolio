# Hephzibah portfolio design system

UI/UX Pro Max informed the portfolio structure, motion, contrast and responsive checks. The user's Next.js and TypeScript stack takes precedence over the skill's mobile defaults.

## Direction
Warm editorial portfolio: off-white canvas, charcoal text, muted lime accents, expressive serif emphasis, quiet sans-serif body type, large project presentations.

## Tokens
Background #f5f3ec; foreground #252b24; secondary text #62685f; border #d6d9ce; accent #dce8b6.
Body DM Sans with Arial fallback; display Manrope with Arial fallback; emphasis Georgia italic.
Content maximum width 1280px; gutters 56px desktop, 32px tablet, 20px mobile.

## Motion
Desktop sticky project stack with subtle scroll-linked scaling. Single-column static project layout at 760px and below. Reveal sections once. Honor prefers-reduced-motion through MotionConfig and CSS; disable sticky animation in reduced-motion mode.

## Content
Use resume facts. Keep illustrative project art labeled. No fabricated project URLs, metrics, reviews or testimonials. StoneCircle has store links but no project-specific role or stack in the resume; do not assign those details.

## Verification
Check 375px, 768px, 1024px, 1440px; keyboard focus and navigation; working project filters and detail pages; published store links; resume download; production build.
